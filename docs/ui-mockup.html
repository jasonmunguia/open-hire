How a candidate moves

  • Reject — out of the stack. Stays listed under Rejected so a mis-swipe is recoverable, but any note typed is discarded with them.
  • Next Round — survives into the next pass. The note is saved and shown again when they come back around.
  • Auto-Bid — pulled out of the review stack entirely. They skip every intermediate round and rejoin the main list only once the pool is down to the top 50.

Notes that follow the candidate

Every note a candidate keeps is stamped with the round it was written in. When they reappear in round 2 or 3, the earlier note sits right above the notes box — tap it to read the full history — and the box below is empty for the new one.

So by the finals you have the whole trail on each person: what struck you at a glance in round 1, and what changed once you read them properly.

Two things this mockup fakes

Resumes here are drawn in HTML; the real app renders each PDF page as an image.

The round threshold is set to 2 candidates so you can watch the auto-bid merge happen in a few taps. In the real thing that number is 50.

Laptop mode shows the layout, not the size — in a real browser it fills the whole window, so the resume gets considerably bigger than the frame here suggests.
